## http status codes -> res.writtenHead

-200 -> OK
-201 -> Created
-400 -> Bad Request
-401 -> Unauthorized
-403 -> forbidden
-404 -> Not Found
-500 -> Internal Server Error

Server can send to the client
1. html content ->prg2 , prg3
2. html file -> prg5
3. jsonn data ->prg4
4. plain file
5. js file
6. any file to download
7. etc
